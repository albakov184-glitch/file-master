Конвертация

Фото (включая HEIC с iPhone), Word, Excel, PowerPoint, PDF, электронные книги, аудио, видео, архивы, шрифты, субтитры.

🗜

Сжатие

Фото, PDF, видео и аудио уменьшаются без заметной потери качества. Любой другой файл упаковывается в ZIP.

📝

Извлечение текста

Из документов, таблиц, презентаций и PDF. Сканы и фотографии распознаются на русском и английском.

📎

Объединение и разделение PDF

PDF, картинки и документы в один файл в нужном порядке. Или наоборот, PDF по отдельным страницам.

📂

Архивы

Распаковка ZIP, RAR, 7Z, TAR, GZ, ISO и других, перепаковка в ZIP, 7Z или TAR.GZ. Русские имена файлов не ломаются.

🕘

Все обработанные файлы можно скачать повторно. Тяжёлые задачи идут в фоне, пользователь видит позицию в очереди.

Запуск

Свой бот за 10 минут

Нужен только сервер с Docker. Бесплатно подойдёт Oracle Cloud Always Free.

  1. Получите токен бота

    Напишите @BotFather в Telegram → /newbot → скопируйте токен.

  2. Скачайте код на сервер 
    git clone https://github.com/albakov184-glitch/file-master.git
cd file-master && cp .env.example .env
  3. Впишите токен в .env и запустите 
    docker compose up -d --build

    Готово — бот отвечает. Больше скорости: docker compose up -d --scale worker=3.
